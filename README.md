# Reverse Snake · 反向贪吃蛇

常规贪吃蛇是你控制蛇去吃豆子；这里反过来：**你是一个点，蛇来追你**。吃掉晶体得分，代价是蛇立刻变长、你能跑的空间更小。看你能撑到几分。

单文件 HTML MVP，无构建、无依赖、无后端。

## 运行

直接双击 `index.html`，或起一个静态服务：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

`index.html` 位于仓库根目录，即静态托管的默认入口。Vercel / GitHub Pages / Netlify 导入仓库即可，无需任何构建或路径配置。

## 操作

| 键 | 作用 |
|---|---|
| `↑ ↓ ← →` / `WASD` | 设定持续移动方向 |
| `Space` | 冲刺 2 格（CD 2.6s） |
| `P` / `Esc` | 暂停 / 继续 |
| `R` / `Enter` | 重开 / 开始 |

## 移动端（iPhone / iPad）

- Safari 直接打开即可。棋盘按可用宽高自适应，刘海 / Home Indicator 通过 `safe-area-inset` 避让。
- 竖屏：HUD 压成一行，棋盘下方显示虚拟方向键（含冲刺），按钮 ≥ 58pt。
- 横屏 / 矮屏：自动压缩外壳并隐藏方向键，改用棋盘上滑动转向 + 点按冲刺，一屏内完成操作。
- 支持滑动连续转向（不必抬手）、屏幕旋转与分屏自动重排；棋盘上已禁用误缩放与页面滚动。

## 规则

| 项 | 规则 |
|---|---|
| 得分 | 吃掉青绿晶体 +1 分 |
| 代价 | 每分让蛇 +2 节，追击速度同步提升 |
| 死亡 | 撞上任意一节蛇身（含蛇头、蛇尾），或被蛇头抓到 |
| 墙 | 只挡路，不致死 |
| 蛇 AI | BFS 寻路，每 3 步才重算方向（有转向惯性，急转弯可甩开） |
| 自锁 | 蛇被自己身体卡住会断尾脱困，避免僵局 |
| 最高分 | 存浏览器 `localStorage` |

所有实体标记严格限制在单个网格内，便于精确判断位置。

## 设计要点

- **负反馈即难度曲线**：得分 → 蛇变长 → 可用空间缩小 → 更难得分。
- **可甩开的追击者**：蛇起步明显慢于玩家（235ms vs 112ms/格），随分数加速到 108ms；转向惯性让走位有意义。
- **HUD 即仪表盘**：分数、最高分、蛇长、可用空间（flood fill 实时计算）、追击强度。
- **视觉**：浅色专业外壳 + 深空精密视窗；能量脊节蛇、橙色信号点、格内锁定环。
